# Retail Zipline

SYNQ supports [Retail Zipline](https://getzipline.com) as a communication platform provider.
This means that all staff-facing notifications generated by SYNQ will be delivered to configurable Zipline teams as Tasks.

To configure SYNQ to use Retail Zipline for your store location you need to:
1. Install the Retail Zipline app on your devices.
2. Determine the Retail Zipline teams that represent groups of workers that should receive notifications.
4. Configure SYNQ to be aware of your Retail Zipline instance and teams.
5. Configure SYNQ apps and devices to send their notifications to your Retail Zipline teams.

Once configured, SYNQ Frontline Hero delivers customer requests from call buttons and QRs to your staff as __Tasks__ in Retail Zipline.

## Supported Modules
Retail Zipline is supported for the following SYNQ modules:
- Call for Help

## Requirements
The following information is required to integrate Retail Zipline with SYNQ Frontline Hero:
- Retail Zipline API client credentials.
- Retail Zipline webhooks that deliver task updates back to SYNQ Frontline Hero.
- Retail Zipline Team IDs that represent the Retail Zipline user groups that should receive notifications.

## Configuration
To provide Frontline Hero with the Retail Zipline API client credentials:
1. Sign into __MyStore__ as a Location Administrator.
2. Select __Configure Store__.
3. Scroll down to __Bot configuration + Channels__.
4. Set __Notification Method__ to `Zipline Bot`.
5. Provide the following:
   - __Zipline Client ID__
   - __Zipline Client Secret__
   - __Zipline Subdomain__
   - __Zipline Username__
   - __Zipline Password__
6. Copy the __Webhook URL__ from the information box.
7. Configure Webhooks in Retail Zipline:
   1. Sign in to the Retail Zipline portal.
   2. Click on your user avatar and select __Settings__.
   3. Click __Webhooks__.
   4. Click __Add Webhook__.
   5. Provide a __Name__. For example, `SYNQ Frontline Hero`.
   6. Paste the copied __Webhook URL__.
   7. Click __Add Webhook__.
   8. Copy the __Secret__.
   9.  To add an event subscription:
       1.  Click __Add Event Subscription__.
       2.  Select the desired event. 
       3.  Click __Add Event__.
   10. Add event subscriptions for the following events:
      - `Task assigned` 
      - `Task unassigned` 
      - `Team task assigned` 
      - `Team task cancelled` 
      - `Team task completed` 
      - `Team task created` 
      - `Team task deleted` 
      - `Team task uncompleted` 
8.  Click __Enable Webhook__.
9.  Return to MyStore.
10. Paste the copied secret into __Zipline Webhook Secret__.
11. Click __Update Location Settings__.

To define a target Retail Zipline group that should receive Frontline Hero notifications:
1. Click the __Add Bot Instance__ button.
2. Provide the following:
   - __Name__: A display name for this group of users. This is how the group will appear elsewhere in MyStore when you are selecting which group will receive notifications.
   - __ID__: The ID of the Retail Zipline team that will receive notifications.
3. Click __Save__.
4. Repeat to add other groups.
